🎲 Digital Dice Using Logic Gates

A digital dice circuit designed using logic gates and digital ICs to generate values from 1 to 6, demonstrating fundamental digital electronics concepts and display interfacing.

[📄 View Project Report](./AADHARSH%20ADVD%20REPORT%20%281%29.pdf)

🎯 Project Objective

To design a digital dice using logic gates and digital ICs, demonstrating the practical implementation of digital electronics concepts.

🛠️ Technologies

- Digital Logic Gates
- Digital Electronics
- Electronic Circuit Design

✨ Features

- Generates dice values from 1 to 6.
- Demonstrates digital logic concepts.
- Provides a practical digital electronics implementation.
