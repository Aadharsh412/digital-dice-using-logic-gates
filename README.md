🎲 Digital Dice Using Logic Gates

A digital electronics mini project that generates dice values from 1 to 6 using a 555 timer, a Mod-6 counter, logic gates, and an LED-based dice display.

📌 Project Overview

The Digital Dice Using Logic Gates project demonstrates the practical application of digital electronics concepts. The circuit uses a clock pulse generator to drive a counter, logic gates to decode the generated states, and LEDs to display the corresponding dice patterns.

The system follows a repeating six-state sequence and provides an educational demonstration of combinational logic, sequential logic, binary counting, and LED interfacing.

🎯 Objectives

- Design a digital dice circuit using digital logic components.
- Generate six valid states using a Mod-6 counter.
- Decode binary counter outputs using logic gates.
- Display dice numbers using LEDs.
- Understand clock generation, counter operation, and reset logic.

⚙️ Working Principle

1. Clock Generation: A 555 timer generates clock pulses.
2. Counter Operation: The counter generates six valid binary states.
3. Logic Decoding: AND, OR, and NOT gates decode the counter outputs.
4. LED Display: LEDs illuminate in patterns representing dice numbers 1 through 6.
5. Reset Operation: After the sixth state, the counter returns to its initial state.

🔢 Counter State Sequence

3| 010
4| 011
5| 100
